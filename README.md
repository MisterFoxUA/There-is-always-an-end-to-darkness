# There-is-always-an-end-to-darkness

## Файли

- `index.html` — головна сторінка з питанням і трьома варіантами: «Шанс є», «Шансу немає»
  і «Судоку». Перші два надсилають відповідь в Apps Script (обрати можна лише раз),
  третій нічого не надсилає — просто відкриває `sudoku.html`.
- `sudoku.html` — сторінка гри: нескінченні задачі, чотири рівні складності, олівець,
  скасування ходу, підказки, підсвітка помилок, секундомір, збереження партії в браузері.
- `sudoku-engine.js` — генерація задач, розвʼязування, оцінка складності.
  Кожна задача має рівно один розвʼязок.
- `sudoku-game.js` — стан однієї партії (ходи, позначки, історія, збереження).

## Перевірки

Тести — це звичайні сторінки, їх достатньо відкрити в браузері:

- `sudoku-tests.html` — рушій і логіка партії (генерація, єдиність розвʼязку, складність,
  конфлікти, олівець, скасування, збереження). `?n=25` — скільки задач генерувати на рівень.
- `sudoku-ui-tests.html` — сама сторінка гри: кліки, клавіатура, підказки, перемикання
  складності, проходження задачі до перемоги й продовження після перезавантаження.

Угорі кожної сторінки видно підсумок: скільки перевірок пройдено.
